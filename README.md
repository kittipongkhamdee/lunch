# ระบบเอกสารอาหารกลางวันนักเรียน

เว็บแอพ (PWA) กรอกรายการอาหารรายวันครั้งเดียว แล้วพิมพ์เอกสารทั้งชุดได้ทันที แทนการป้อน Excel → เชื่อม Word

- ใช้ได้ทั้งคอมพิวเตอร์/แท็บเล็ต/มือถือ ติดตั้งเป็นแอพได้ ทำงานออฟไลน์ได้
- ไม่มีเซิร์ฟเวอร์ ข้อมูลเก็บในเบราว์เซอร์ของเครื่อง (สำรอง/ย้ายเครื่องด้วยไฟล์ .json ในหน้าตั้งค่า)
- เอกสาร: ใบจัดซื้อ, ใบรับรองการจ่ายเงิน, บันทึกขออนุมัติเบิกจ่าย (ประธานกรรมการ/หัวหน้าการเงิน), บันทึกรายงานผู้ควบคุม, ใบตรวจรับพัสดุ

## รันในเครื่อง
```
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```
นำโฟลเดอร์นี้ไปวางบนเว็บโฮสต์แบบ static ที่ใดก็ได้ (HTTPS) เพื่อใช้งานบนมือถือ

## ข้อมูลเริ่มต้น
`data/seed.json` สร้างจาก Excel เดิมด้วย `tools/build_seed.py` (ข้อมูลโรงเรียนจริง — หากเผยแพร่สาธารณะให้ลบไฟล์นี้ก่อน)
